# 💬 Real-Time Chat App

A full-stack real-time messaging application built with the MERN stack and Socket.io, featuring private 1-on-1 conversations, live typing indicators, and read receipts.

**[Live Demo](chat-app-ragyajains-projects.vercel.app)** 

---

## Features

- **Real-time messaging** — instant delivery powered by WebSockets (Socket.io), no page refresh needed
- **User authentication** — secure signup/login with JWT tokens and bcrypt password hashing
- **Private 1-on-1 chat** — messages are scoped to Socket.io rooms so conversations stay private between two users
- **Contacts system** — sidebar shows only the people you've actually messaged, with a separate "New Chat" flow to start a conversation with anyone else on the platform
- **Online presence** — every contact shows a live online/offline indicator, not just currently-connected users
- **Typing indicators** — see when the other person is typing, in real time
- **Read receipts** — single tick for sent, double tick for seen (WhatsApp-style)
- **Media sharing** — send images, PDFs, and voice messages, backed by Cloudinary
  - Images are compressed client-side before upload (via `browser-image-compression`) to cut payload size without a visible quality loss
  - Voice messages are recorded directly in the browser using the `MediaRecorder` API and played back with a native audio player
- **Delete messages** — sender can delete a message for both sides in real time; it's replaced with a "This message was deleted" placeholder
- **Notifications** — three layers, all in real time:
  - Unread message badges per contact in the sidebar
  - In-app toast pop-ups for new messages from chats you're not currently viewing
  - Native browser push notifications when the tab is inactive or minimized
- **Persistent chat history** — all messages stored in MongoDB, so conversations survive refreshes and reconnects
- **Responsive UI** — built with Tailwind CSS with a custom design system (custom color palette, Plus Jakarta Sans/Inter typography), works cleanly across screen sizes

### How private messaging works

Each pair of users gets a deterministic **room ID**, generated by sorting and joining both usernames (e.g. `karan` + `arjun` → `karan-arjun`). When two users open a chat, both join that room via `socket.join()`, and all messages between them are emitted with `io.to(roomId).emit(...)` — scoping delivery to just that room instead of broadcasting to every connected client.

Message deletion follows the same room-scoped pattern, with a server-side ownership check (`msg.senderId !== sender`) before allowing a delete, so a user can only delete their own messages — never someone else's.

## Getting Started

### Prerequisites
- Node.js (v18+)
- A MongoDB Atlas account (or local MongoDB instance)

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/ragyajain/chat-app.git
   cd chat-app
   ```

2. Install backend dependencies
   ```bash
   cd server
   npm install
   ```

3. Install frontend dependencies
   ```bash
   cd ../client
   npm install
   ```

4. Set up environment variables

   `server/.env`
   ```
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   ```

   `client/.env`
   ```
   VITE_BACKEND_URL=http://localhost:5000
   ```

5. Run the app
   ```bash
   # Terminal 1 — backend
   cd server
   npm run dev

   # Terminal 2 — frontend
   cd client
   npm run dev
   ```

6. Open `http://localhost:5173` in two different browser windows to test real-time messaging between two users.
